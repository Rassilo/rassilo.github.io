CTO & Co-Founder · Laevitas

Own architecture, infrastructure, security and the engineering team for a crypto derivatives analytics platform.
  • Re-architected core analytics from cron/batch jobs to an event-driven pipeline on NATS JetStream and Redis Streams — producer–consumer, replay, at-least-once delivery, sub-second data latency.
  • Benchmarked MongoDB Atlas, AWS Aurora and other managed databases against 1.5 TB of lagging market data, then consolidated onto ClickHouse on bare metal: over $8,000 a month saved, multi-second queries → sub-second.
  • Architected and operate self-managed Kubernetes (k3s) on bare metal across production and analytics clusters — HA ClickHouse, zero-downtime rollouts, autoscaling, infrastructure as code.
  • Raised public API availability to 99.99% with caching, sliding-window rate limiting, graceful degradation and SLO alerting.
  • Shipped AI-native access: an MCP server exposing 30+ market-data tools with OAuth 2.1, plus LLM-driven anomaly detection over live derivatives flow.
  • Own billing end to end — Stripe subscriptions, entitlements, webhooks and invoicing tied to API-key tiers and quotas, plus x402 on-chain pay-per-request micropayments.
  • Built observability from zero (Grafana, Prometheus, Elasticsearch) and automated runbooks with n8n, including a custom Redis Streams trigger node.
